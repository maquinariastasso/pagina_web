# Maquinarias Tasso

Sitio estático de **Arriendo de Maquinarias Tasso Ltda.**, publicado mediante GitHub Pages en [maquinariastasso.cl](https://maquinariastasso.cl).

## Estructura

- `index.html`: contenido y metadatos del sitio.
- `styles.css`: diseño adaptable a computadores y celulares.
- `script.js`: menú móvil y preparación de solicitudes por correo.
- `assets/`: fotografías y logotipos.

El botón de WhatsApp, el teléfono y el correo pueden actualizarse directamente en `index.html`. La dirección usada por el formulario de cotización también aparece en `script.js`.
